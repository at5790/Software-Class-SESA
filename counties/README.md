# County code

This directory contains the code and raw data for counties.

Raw data:

- `census_counties.txt`: Census 2020 county file for the whole US.
  Downloaded 2026-11-03 from
  https://www2.census.gov/geo/docs/reference/cenpop2020/county/CenPop2020_Mean_CO.txt
  (renamed, not edited)

To load: `python -m counties.load`
