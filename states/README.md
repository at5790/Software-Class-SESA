# State code

This directory contains *code*, *raw data*, and *JSON files* for the state part of our
project.

Raw data:

- `states.csv`: state codes, names and locations (from the starter repo)
- `census_states.txt`: Census 2020 state file, used for the FIPS codes.
  Downloaded 2026-10-27 from
  https://www2.census.gov/geo/docs/reference/cenpop2020/CenPop2020_Mean_ST.txt
  (renamed, not edited)

To load: `python -m states.load`
